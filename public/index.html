Triangle Strategy Save Editor

Open a SaveData_N.sav, change values, download the edited save. Everything runs in your browser; the file is never uploaded. Feedback or a bug? Open an issue on GitHub.

Unofficial and experimental. Use at your own risk. This editor is not fully tested, and an edited save may fail to load or break your progress. Back up your saves first. Disclaimer

Second conviction array advanced

A second int[4] stored right after the convictions (meaning unknown; 50 for Utility in the sample save).

Battle orders advanced

Count and the second flag as stored by the game (meaning of the flag unconfirmed).

Shop stock advanced

Remaining stock per shop entry.

Level and EXP are the safest edits. The game may recompute other stats from level and class when the save loads.

Character stories

"Unlocked" is the story's unlock flag from the game's character-story table. "Viewed" means it was opened in the Character Stories menu (read-only). Unlocking through the flag has not been tested in game.

Character-story achievements

Per-unit tracker the game keeps for the character-story achievements. It sets flags 6, 7 and 8 when that unit's world-map story events of those types finish. At the moment the last of the three becomes 1, it unlocks Steam ACHIEVEMENT_(080 + slot). Ticking all three in the save does not fire it, because the game must set the last flag itself. To re-send a missing achievement (verified in game), take a unit with exactly one flag still off and set its slot (advanced) to the target. Then play that unit's story from the world map. The Character Stories re-watch menu does not count. Steam only receives achievements that aren't unlocked yet.

Story chart advanced

Four flags per chart node as stored by the game (meanings unconfirmed). Chapter progress itself is driven by the CHAPTER_START/END flags on the Event flags tab.

Dialogue choices advanced

One flag per decision option the game tracks.

Achievement counters

Lifetime counters the game checks for achievements (id 40 = total gold earned). Raising one can unlock a Steam achievement the next time the game updates it.

Places visited advanced

Seen notes, information & tutorials

Read-only.

Event flags advanced

Every story/event flag the game defines (chapter start/end, events, world-map icons, quests…). Changing these can break story progression. Each world-map event has two flags: WI_END_… is set when it is done in this playthrough, and WI_END_…_EX when it was done in any playthrough (kept in New Game+; inferred from save data). Events marked "no world-map icon" are never set in our sample and are probably unused. Search matches chapter, place and event type too.

Raw parsed data

Everything else the parser decodes, read-only. Values shown as {v, at} are stored at plaintext offset at.
