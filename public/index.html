Triangle Strategy Save Editor

Open a SaveData_N.sav, change values, download the edited save. Everything runs in your browser; the file is never uploaded. Feedback or a bug? Open an issue on GitHub.

Unofficial and experimental. Use at your own risk. This editor is not fully tested, and an edited save may fail to load or break your progress. Back up your saves first. Disclaimer

A late-game save (SaveData_4), to try the editor without your own file.

★ marks the tabs most worth editing: money, convictions, inventory, accessories, units and achievement counters. The rest show everything else in the save.

Character stories

"Unlocked" is the story's unlock flag from the game's character-story table. "Viewed" means it was opened in the Character Stories menu (read-only). Unlocking through the flag has not been tested in game.

Event flags advanced

Every story/event flag the game defines (chapter start/end, events, world-map icons, quests…). Changing these can break story progression. Each world-map event has two flags: WI_END_… is set when it is done in this playthrough, and WI_END_…_EX when it was done in any playthrough (kept in New Game+; inferred from save data). Events marked "no world-map icon" are never set in our sample and are probably unused. Search matches chapter, place and event type too.
